# Restaurant PWA

A Progressive Web Application (PWA) designed for restaurants. This project contains both the frontend application and the backend API service.

## Project Structure

```
├── frontend/     # Frontend Web Application (PWA)
├── backend/      # Backend API Service
├── docs/         # Documentation and specs
└── database/     # Database configuration, schema, and migrations
```
